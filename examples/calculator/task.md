Create `calculator.py` in the workspace.

Implement these functions:

- `add(a, b)`
- `subtract(a, b)`
- `multiply(a, b)`
- `divide(a, b)`

Use only the Python standard library. Preserve numeric precision naturally for `int`, `float`, and `Decimal` inputs. `divide(a, b)` must raise `ZeroDivisionError` when `b == 0`.

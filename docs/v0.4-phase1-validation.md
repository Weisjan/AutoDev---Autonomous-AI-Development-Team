## Supported boundary and limitations

Phase 1 supports Python execution with trusted pre-existing stage tests and sandbox dependencies,
plus scoped documentation, JSON data and static assets. It does not install model-selected packages,
write authoritative tests/control manifests, build generated Node/React projects, launch generated
services, replan validated prerequisites or force-resume an unsafe checkpoint. Cancellation is
terminal; pause waits for a verified boundary. Unsafe recovery is refused and needs manual review
and explicit confirmation of a new run. No source merge, push, rollback or cleanup is automatic.

See [README](../README.md#multi-stage-projects-v04-phase-1) for Windows commands, the trusted
invoice demonstration and recovery semantics. Rebuild the Docker image before a real v0.4 run
because it contains baked AutoDev source. Existing kernel/resource restrictions are unchanged.
